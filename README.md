# DoAide Docs

Free document generator for Indian businesses and individuals. Generate rent receipts, rental agreements, salary slips, experience letters, invoices and more — all free, no login required.

**Live at:** https://docs.doaide.com

## Tech Stack
- Frontend: React + Vite
- Backend: FastAPI
- PDF: jsPDF (client-side)
- Deploy: Hetzner

## Development
```bash
cd web && npm install && npm run dev
cd api && pip install -r requirements.txt && uvicorn app.main:app --reload --port 3067
```
